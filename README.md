# Mangatarem Cultural Hub 🗺️

An interactive digital cultural map and local tourism information system dedicated to showcasing the rich heritage, vibrant festivals, and natural wonders of **Mangatarem, Pangasinan**.

![Hero Image](https://ilovepangasinan.com/wp-content/uploads/2020/02/Daang-Kalikasan-3.jpg)

## 🌟 Overview

The **Mangatarem Cultural Hub** serves as a centralized platform for tourists, researchers, and residents. It bridges the gap between traditional heritage and modern technology, providing a high-performance, responsive interface for discovering everything the town has to offer—from the scenic heights of *Daang Kalikasan* to the rejuvenating springs of *Manleluag*.

## 🚀 Features

- **Interactive Cultural Map**: A tailored Leaflet.js implementation featuring barangay-level cultural highlights, historical markers, and nature trails.
- **Gemini-Powered AI Guide**: An integrated AI tourism consultant that provides real-time cultural insights and personalized 1-day itineraries using the Google Gemini API.
- **Community Calendar**: A dedicated monthly events system for tracking local festivities, religious celebrations, and LGU-supported activities.
- **Role-Based Dashboards**: 
  - **Public User**: Seamless exploration and information gathering.
  - **Barangay Admin**: Tools to manage local assets, propose new markers, and upload cultural media.
- **High-Performance UI**: Built with a "Mobile-First" philosophy using Tailwind CSS and Lucide icons for a premium aesthetic.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS (Modern, utility-first UI)
- **Mapping**: Leaflet.js with OpenStreetMap tiles
- **AI Engine**: Google GenAI (Gemini 3 Flash)
- **Icons**: Lucide React
- **Charts**: Recharts (for LGU analytics)

## 📦 Getting Started

### Prerequisites

- A modern web browser.
- A Google Gemini API Key (for the AI Guide functionality).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/mangatarem-cultural-map.git
   ```
2. Open `index.html` in your browser (or use a local development server like Vite/Live Server).

### Environment Configuration

The application requires a Gemini API key to be available in the environment. Ensure `process.env.API_KEY` is configured in your deployment environment (e.g., Vercel, Netlify, or a `.env` file for local development).
